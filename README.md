# 拾題｜錯題本

適合手機操作的繁體中文網頁 App。原生 HTML、CSS、JavaScript，無需安裝前端依賴。

## GitHub Pages 部署

支援兩種發布來源：選擇 **Deploy from a branch → main → / (root)** 時，根目錄的 `index.html` 會自動導向 `dist/index.html`；選擇下方的 **GitHub Actions** 時則直接將 `dist` 發布為網站根目錄。根目錄 `.nojekyll` 可避免將 README 產生為首頁。

已加入 `.github/workflows/pages.yml`。在儲存庫 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**，再到 **Actions → Deploy to GitHub Pages → Run workflow** 執行首次部署。之後推送至 `main` 會自動檢查語法、執行測試並發布 `dist`。

預期網址為 `https://leohong.github.io/wrong-question-book/`，需待 Actions 部署成功後才可使用。網頁資源使用相對路徑，可在儲存庫子路徑下運作。部署僅包含 `dist`，不會發布測試、Git 歷史或 Sites 設定。

此儲存庫與 GitHub Pages 網站目前為公開。題庫與照片只保存在使用者的瀏覽器，不會隨程式碼推送。

換網址前，請在原本 Sites 網站的「設定與資料」匯出完整備份，再到 GitHub Pages 網址匯入。IndexedDB 依網站來源隔離，題庫不會隨程式部署搬移，也不會上傳到 GitHub。舊網址的資料仍保留在原瀏覽器。

官方說明：https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## 使用

執行 `npm start`，開啟 `http://127.0.0.1:4173`。拍照功能由裝置與瀏覽器的圖片選擇器提供；桌面可選取照片。手機請透過部署後的 HTTPS 網址使用。

1. 新增題目，拍照或選取 JPG／PNG／WebP 等瀏覽器支援的圖片。
2. 用手指或滑鼠拖曳框選；支援重新框選及保留全圖。
3. 配對答案照片或在答案卡「手動輸入答案」填寫文字（最多 10,000 字，支援多行），也可兩者一起使用，或儲存後再補答案。文字答案可參與練習並包含在備份中；無答案題目不參與練習。
4. 選擇分類、出題範圍與 20／30／自訂 1–200 題，題目不足時採實際可用數量。每場不重複。
5. 作答後揭曉答案，自行判定正確與否，逐題儲存。
6. 在統計查看題目數、間隔複習比例、各科掌握情況與最近七天作答紀錄。

## 熟練規則

預設連續答對 3 次（可改為 1–10 次）後進入間隔複習。答對後的間隔依序為 1、3、7、14、30 天，再持續每 30 天。任何階段答錯即重置為待熟練。時間自本次判定起算。提前練習同樣更新熟練度。

## 資料保存與搬移

這是單機版，不含登入同步或 OCR／自動批改。IndexedDB v2 將 `questions`、`images`、`thumbnails`、`reviewLogs`、`settings` 分開儲存。分類與門檻保留在小型設定紀錄中。照片使用 Blob，以 SHA-256 內容雜湊去重；更換或刪除照片時，只有最後一個引用被移除後才刪除實體照片。

答題僅寫入有變動的題目、一筆作答紀錄及儲存版本，不重寫照片。題庫每批顯示 30 題，列表依可見範圍讀取 360 px 縮圖；開啟卡片與答案時才讀原圖。移除畫面後釋放物件 URL。題目與作答的輕量中繼資料目前仍載入記憶體以供統計，尚未改成全面游標查詢。

拍照裁切後可選清晰（1800 px／品質 .92）、平衡（1600 px／.84）或省空間（1200 px／.72），比較 JPEG 與 WebP 的實際檔案大小後採较小版本。提供壓縮後預覽、原始像素檢查及大小顯示；已有照片不會自動有損重壓縮。原始圖片限制 35 MB。

首次載入舊題庫時，先驗證並轉換圖片，全部寫入成功才在同一交易中移除舊紀錄；失敗保留原題庫並提供原始 JSON 下載。請先關閉其他舊版分頁；舊分頁不能覆寫新資料庫，應重新載入。遷移需暫時容納新舊資料，空間不足時可先匯出原始題庫。

新版 ZIP 備份包含 `manifest.json` 與按雜湊命名的獨立照片，共用照片只存一次，不包含可重建的縮圖。輸出、讀入採分塊處理，但最終備份 Blob 和待匯入資料仍需裝置記憶體，因此單次 ZIP／解壓總量上限 512 MB；舊 JSON 匯入保留 200 MB 上限。照片已壓縮，ZIP 主要負責打包，不再重壓照片。匯入檢查完整性、版本、欄位與照片雜湊，確認後原子取代。失敗不覆蓋原資料。瀏覽器清除資料仍會失去題庫，請定期備份。

ZIP 使用隨網站附帶的 fflate 0.8.3（MIT，授權見 `dist/vendor/fflate-LICENSE.txt`）；網頁執行不依賴外部 CDN。

## 驗證

先執行 `npm ci` 安裝測試依賴；`npm run check` 檢查 JavaScript 語法。`npm test` 除練習規則外，也驗證 v1 遷移、1,000 題的局部寫入、照片去重與清理、多分頁衝突、ZIP／JSON 還原及損壞備份不覆寫資料。IndexedDB 測試使用 fake-indexeddb，不代表真實手機效能數據。

未執行真實手機相機／觸控端到端測試。WebMCP 僅於支援的瀏覽器註冊題庫摘要、新增分類與開始練習工具；此環境沒有可用的 WebMCP 驗證上下文，尚未驗證實際註冊與呼叫。

## 答案卡數學公式

手動答案支援 LaTeX：用 `$...$` 包住行內公式（例如 `$-\frac{19}{7}$`），用 `$$...$$` 包住獨立公式，也支援 `\(...\)` 與 `\[...\]`。編輯時可即時預覽；題庫與練習使用相同排版。錯誤或未配對的公式保留原文，儲存與備份保留原始文字。

KaTeX 的程式、樣式、字型及 MIT 授權隨網站存放於 `dist/vendor/katex`，不依賴 CDN。公式設定依 [KaTeX 官方文件](https://katex.org/docs/autorender)。

題目卡也支援手動輸入多行文字與 LaTeX（最多 10,000 字），提供即時預覽。可只輸入題目文字或搭配照片；題庫列表、卡片詳情及練習均顯示公式。純文字題目與答案會一起保存在完整備份中。
